# ELEVEN v3 — Official Web Experience

The web experience for ELEVEN v3, featuring interactive 3D Three.js components, cognitive state visualization, and security audit documentation.

## Features
- **3D Cognitive Orb & Holographic Gyro:** WebGL interactive elements powered by Three.js and custom GLSL shaders.
- **Next.js 16 App Router:** Optimized pages with full SEO metadata and strict Content Security Policy headers.
- **Enterprise Security:** Comprehensive CSP, HSTS, X-Content-Type-Options, and origin isolation.

## Deployment
Deployed continuously to Vercel via GitHub CI/CD integration on branch `main`.
